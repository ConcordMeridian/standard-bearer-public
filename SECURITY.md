# Security policy

This repository contains Standard Bearer Observer v0.1, a research release that evaluates recorded, synthetic agent snapshots offline. It does not monitor live agents, enforce authorization, or provide independent witnessing. Its evidence is self-attested. The known limits of its integrity checks are described in the README under "Integrity is not independence"; reports that sharpen or extend those limits are welcome.

To report a security concern about Standard Bearer, please do not open a public issue. Report it privately through GitHub: on this repository's **Security** tab, choose **Report a vulnerability**.

Never include real credentials, tokens, or confidential deployment configurations in any report or issue. Reduce the problem to a synthetic example.
